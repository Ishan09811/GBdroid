# GBdroid

GBdroid is an android gb, gbc, sgb, gba emulator using mGBA core.

### Features 
- game folders
- listing games with accurate icons and information
- native 59.73* framerate rendering
- fast forward
- fps indicator
- settings
- bios manager
- Material3 UI
